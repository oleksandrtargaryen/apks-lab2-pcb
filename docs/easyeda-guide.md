# Покрокова інструкція: EasyEDA (Standard, web) — лабораторна №2

Усі числа беруться з [`tables.md`](tables.md) (генерується `python3 guid.py`).
Нижче позначка **📸** означає скріншот, який потрібен для звіту — зберігай у `docs/img/` з указаною назвою.

GUID: `81c375e7-d203-505f-a3ce-e051c5794f3a` → U1 8×8 мм (8 пінів), U2/U3/U4 4×4 мм (4 піни), U5 12×12 мм (12 пінів).

---

## 0. Підготовка
1. Відкрити <https://easyeda.com/editor> (Standard Edition), увійти.
2. **File → New → Project** → назва `APKS_Lab2_Bartoshko`.
3. Скрізь перемкнути одиниці в **mm** (права панель *Canvas Properties → Units = mm*).

## 1. Футпринти U1–U5 (PCB Lib)
Для кожного компонента:
1. **File → New → PCB Lib** (футпринт). Назва: `SQ8_U1`, `SQ4_U2`, `SQ4_U3`, `SQ4_U4`, `SQ12_U5`.
2. Шар **TopSilkLayer**: інструмент *Rectangle* — квадрат із центром у (0,0), сторона = розмір компонента (8 / 4 / 12 мм). Найпростіше: намалювати будь-який прямокутник, потім у правій панелі задати X, Y, Width, Height (X = Y = −сторона/2).
3. Інструмент **Pad** (клавіша `P`): Shape *RECT*, Layer *TopLayer*, розмір **1.0 × 0.6 мм** (для U2–U4 можна 0.8 × 0.6). Number = номер піна, координати X/Y — з таблиці *«Координати контактних площадок»* у `tables.md`. Площадки на лівій/правій стороні орієнтувати горизонтально (1.0 по X), на верхній/нижній — вертикально (Rotation 90°).
4. Перевірити кількість пінів (8 / 4 / 4 / 4 / 12) і **Save**.

## 2. Символи U1–U5 (Schematic Lib)
1. **File → New → Schematic Lib**. Назва `U1_81c375e7` тощо.
2. Прямокутник-корпус, далі **Place → Pin** для кожного піна: *Number* = номер (1..N), *Name* = символ GUID (`8`, `1`, `c`, …). Порядок пінів — як у таблиці «Компоненти».
3. Права панель → **Package** → вибрати відповідний футпринт із кроку 1 (*Footprint Manager* має показати відповідність Pin ↔ Pad, без червоних помилок).
4. **Save**.

## 3. Принципова схема
1. **File → New → Schematic** у проєкті.
2. Ліва панель **Library → Personal (Work Space)** — поставити U1–U5.
3. Роз'єм **J1**: у Library знайти `HDR-1X5` / `Header-Male-2.54_1x5` (будь-яка однорядна гребінка 1×5, крок 2.54).
4. З'єднання — найзручніше **Net Label** (клавіша `N`) на кожен пін, ім'я кола з таблиці:
   - `N_0`: U2.3, U3.2, U5.2
   - `N_1`: U1.2, U5.4
   - `N_3`: U1.4, U2.4, U4.2, U5.11
   - `N_5`: U1.6, U3.1, U3.3, U5.3, U5.6
   - `N_7`: U1.5, U1.8, U5.7
   - `N_A`: U4.1, U5.12
   - `N_C`: U1.3, U4.3, U5.5
   - `N_E`: U1.7, U4.4, U5.1
   - `N_F`: U3.4, U5.10
   - вільні піни → J1: `FREE_2` U2.2–J1.1, `FREE_4` U5.9–J1.2, `FREE_8` U1.1–J1.3, `FREE_9` U5.8–J1.4, `FREE_D` U2.1–J1.5

   (Замість міток можна проводити дроти `W` — результат той самий; рівнозначні піни U1.5/U1.8 і U3.1/U3.3, U5.3/U5.6 просто входять в одне коло.)
5. **Design → Design Manager → Nets** — перевірити, що є 9 кіл `N_*` і 5 кіл `FREE_*`, без *unconnected*. Додати рамку/титульний штамп (ПІБ, група).
6. **📸 `schematic.png`** — уся схема, видно всі з'єднання.

## 4. Плата (PCB Layout)
1. На схемі: **Design → Convert Schematic to PCB**. У діалозі контуру плати: *Rectangle*, **Width 85.6 mm, Height 53.98 mm**, Layers = **2**. (Округлення кутів R = 3.18 мм — як у справжньої картки, за бажанням: *Board Outline → Round corner*.)
2. **Edit → Canvas Origin → From Board Outline** (лівий нижній кут = 0,0).
3. Розставити компоненти за таблицею (виділити → права панель X/Y):

   | Елемент | X | Y |
   |---|---|---|
   | J1 | 5.0 | 27.0 |
   | U1 | 24.0 | 33.0 |
   | U2 | 22.0 | 17.0 |
   | U5 | 44.0 | 27.0 |
   | U4 | 62.0 | 35.0 |
   | U3 | 62.0 | 18.0 |

   J1 — на лівій короткій стороні (вимога: вільні піни виводяться на край з однієї меншої сторони). Можна підсунути/повернути для коротших зв'язків — `docs/img/layout_preview.png` показує ratsnest.
4. **Design → Design Rules**: Track width **0.25 mm**, Clearance **0.2 mm**, Via diameter **0.6 mm**, Via drill **0.3 mm**.
5. Трасування (двошарове): *Route → Auto Router* (Layers: Top+Bottom, Corner = 45°) **або** вручну інструментом *Track* (`W`), перехід на інший шар — клавіша `V` (переходовий отвір). Уникати кутів 90°/гострих — режим 45°. Мінімізувати довжину.
6. За бажанням: 3D-перегляд **View → 3D View** (гарно для звіту).
7. **📸 `pcb_layout.png`** — уся плата з контуром 85.6×53.98, видно компоненти і доріжки обох шарів.

## 5. DRC
1. **Design → Check DRC** (права панель *Design Manager → DRC Errors → Refresh*).
2. Має бути **0 errors**. Якщо є — зазвичай це clearance: розсунути доріжки або ще раз автотрасувати.
3. **📸 `drc.png`** — панель DRC із «No errors» / 0.

## 6. Gerber
1. **Fabrication → PCB Fabrication File (Gerber)** → *Generate Gerber*.
2. Завантажений zip покласти в репозиторій як `gerber/Gerber_APKS_Lab2_Bartoshko.zip`.
3. **📸 `gerber.png`** — діалог/перелік файлів Gerber (необов'язково).

## 7. Що повернути в репозиторій
- `docs/img/schematic.png`, `docs/img/pcb_layout.png`, `docs/img/drc.png` (+ `gerber.png`, `pcb_3d.png` за бажанням);
- `gerber/*.zip`;
- (опційно) експорт проєкту EasyEDA: **File → Export → EasyEDA Source** → `easyeda/`.

Після цього Claude допише звіт (`reports/lab2`).
